# ⚡ Hussain — Full-Stack Developer Portfolio

A cinematic, WebGL-powered portfolio built with **Next.js 15**, **Three.js (react-three-fiber)**, **Tailwind CSS** and **Framer Motion**.

## ✨ Highlights

- **Scroll-driven 3D world** — the camera descends through a glowing particle universe as you scroll, flying past a morphing hero core, portal rings, and a crystal cluster
- **Custom two-part cursor** with spring physics and contextual hover labels
- **Cinematic preloader** with animated counter and clip-wipe reveal
- **Lenis smooth scrolling** wired into anchor navigation
- **Magnetic buttons**, 3D-tilt project cards, animated stat counters, proficiency bars
- **Dual-direction infinite marquees**, scroll progress bar, film-grain overlay
- Fully responsive, dark neon aesthetic (cyan → violet → fuchsia)

## 🛠 Stack

| Layer     | Tech                                          |
| --------- | --------------------------------------------- |
| Framework | Next.js 15 (App Router, TypeScript)           |
| 3D        | Three.js, @react-three/fiber, @react-three/drei |
| Motion    | Framer Motion, Lenis                          |
| Styling   | Tailwind CSS v4                               |

## 🚀 Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## 🎨 Customizing

All content (name, tagline, stats, skills, projects, experience, socials) lives in **`src/lib/data.ts`** — edit one file to make it yours.
